# Innovtelier

Professional support services and legal case management platform.

## About

Innovtelier provides professional support services to attorneys, nonprofits, and small businesses. All legal support is offered exclusively under the supervision of a licensed attorney.

## Services

- **Legal Support Services** - For attorneys and law firms
- **Non-Profit Support** - For nonprofits and community organizations
- **Organization & Productivity Strategy** - For all clients

## Products

- **Case Management System** - Modern legal case management for growing law firms

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage for data persistence
- Chart.js for analytics
- Font Awesome for icons

## Features

- Client intake forms
- Paralegal dashboard
- Reports and analytics
- Family law specialized tracking
- WCAG 2.1 AA accessible
- Winston & Strawn inspired design

## Local Development

Simply open `index.html` in a web browser. No build process required.

Deployed on Vercel. See deployment guide for details.
